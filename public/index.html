监控代理

节点密码不会回显。带插件的 SS 节点请使用现有客户端的 HTTP 代理端口。

支持 HTTP / HTTPS 代理与 Shadowsocks 分享链接，Docker 已内置 SS 客户端。测试代理无需填写网站；验证成功后才替换已保存代理，并应用到当前账户的网页和接口监控，原检测记录保留。
